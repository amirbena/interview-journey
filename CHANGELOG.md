# Changelog

Released versions are summarized here by the release automation from merged
pull requests. See [`policies/release-and-changelog.md`](policies/release-and-changelog.md).

## 1.0.0 - 2026-10-16

### Features

- Interview Journey methodology: core policies, fifteen canonical frameworks, record schemas, workflows, and output templates
- Claude Skill, Claude Project instructions, and Claude external install kit
- ChatGPT Custom GPT package with three traceable Knowledge bundles and a `deployment-release.json` provenance record
- Public interview research with evidence classes, freshness rules, and bounded routing
- Offer and negotiation preparation across all three packages
- Repository validation, deterministic Bash and PowerShell packaging scripts, and a synthetic example journey
