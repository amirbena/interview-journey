# Synthetic Candidate — Golden Journey

> **This entire example is fictional.** The candidate ("Maya Chen"), the company ("Solstice Cloud"), the recruiter, the interviewers, the questions, and the feedback below are all synthetic and were invented solely to demonstrate the Interview Journey methodology end to end. No real person, company, or event is represented.

This directory walks through one complete Interview Journey, in order, showing every framework's output feeding the next:

1. [`source-profile.md`](source-profile.md) — the candidate's fictional resume/background input.
2. [`role-intelligence.md`](role-intelligence.md) — Framework 01 output for the target role.
3. [`resume-intelligence.md`](resume-intelligence.md) — Framework 02 output.
4. [`interview-process.md`](interview-process.md) — the known interview process and current stage (Frameworks 03).
5. [`role-fit-gap-analysis.md`](role-fit-gap-analysis.md) — Framework 04 output.
6. [`preparation-strategy.md`](preparation-strategy.md) — Framework 06 output.
7. [`question-predictions.md`](question-predictions.md) — Framework 07 output.
8. [`interview-hypotheses.md`](interview-hypotheses.md) — Framework 08 output.
9. [`system-design-preparation.md`](system-design-preparation.md) — one targeted preparation output (Framework 10).
10. [`mock-interview-excerpt.md`](mock-interview-excerpt.md) — one mock interview excerpt (Framework 12).
11. [`post-interview-debrief.md`](post-interview-debrief.md) — one post-interview debrief (Framework 14).
12. [`interview-journey-state.md`](interview-journey-state.md) — the updated Interview Journey State after the debrief, including next-stage preparation.

Every file in this directory is a repository development asset used to demonstrate the methodology. It is never packaged into the Claude Skill ZIP, the Claude external kit, or the ChatGPT Knowledge bundles — see [`claude/skill-manifest.md`](../../claude/skill-manifest.md#intentionally-excluded-files) and [`chatgpt/knowledge-manifest.md`](../../chatgpt/knowledge-manifest.md#what-knowledge-must-not-contain).
