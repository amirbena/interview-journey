# Answer Coaching

Canonical source: [`frameworks/13-answer-coaching-framework.md`](../../../frameworks/13-answer-coaching-framework.md).

## Purpose

Improve interview answers through structured coaching — never rewrite the candidate's actual experience, only how it is communicated.

## Core rules

Never invent experiences or achievements (AC-001); preserve the candidate's intent (AC-002); improve clarity before style (AC-003); prioritize substance over wording (AC-004); feedback must be specific and actionable (AC-005); explain *why* an answer is weak (AC-006); adapt coaching to the interview type (AC-007).

## Review workflow

Read the answer → identify the interview objective → check whether the question was actually answered → evaluate structure → evaluate technical correctness → evaluate ownership → evaluate business impact → evaluate communication quality → suggest improvements → produce an improved version only if requested.

## Common weaknesses

Doesn't answer the question, too long, too short, no ownership, missing results, missing trade-offs, weak technical explanation, vague language, unsupported claims, buzzwords without evidence.

## Output

Overall Assessment, Strengths, Weaknesses, Coaching Recommendations, Suggested Follow-up Questions, Improved Answer (optional, only on request).
