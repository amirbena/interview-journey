# Privacy Guide

## What belongs in shared Project Knowledge

Only the eleven canonical `core/` methodology files in `knowledge/` — never personal data.

## What never belongs in shared Knowledge or the Skill

- Your real resume text.
- A real Job Description tied to a company you're actually interviewing with (paraphrase or keep it in your own conversation instead).
- Real recruiter or interviewer names, messages, or feedback.
- Real interview questions you were actually asked, if you'd rather they stay private.
- Any file you wouldn't want visible to anyone else who might gain access to this Project.

## Where personal data does belong

- Your own conversation with the assistant.
- Your own private Project workspace files (see the "Optional private workspace files" list in [`../knowledge-manifest.md`](../knowledge-manifest.md)) — added only to a Project you personally control, never a shared/team one.

## What this kit does not do

- It does not implement persistence, retention, or a database. Anything the platform doesn't itself retain is not retained.
- It does not monitor recruiters, interviewers, or companies in the background.
- It does not send messages, schedule interviews, or take any action on your behalf.
- It does not guarantee cross-conversation memory — see [`../../core/state-management.md#context-boundary`](../../core/state-management.md#context-boundary).
