# Knowledge Files

The `knowledge/` folder in this kit contains twelve canonical `core/` files, unchanged from the source repository, to be uploaded as Project Knowledge:

| File | Purpose |
|---|---|
| `product-definition.md` | What Interview Journey is and its main outputs. |
| `terminology.md` | Canonical term definitions used across all frameworks. |
| `scope-and-non-goals.md` | What's in scope for this MVP and what is explicitly excluded. |
| `workflow.md` | Operating modes and interview mode boundaries. |
| `orchestration-policy.md` | The master orchestrator's routing table and skip rule. |
| `evidence-policy.md` | What must never be invented and how evidence is classified. |
| `accuracy-policy.md` | Confidence levels and how precision is expressed. |
| `context-priority.md` | The input priority order used across every framework. |
| `quality-gates.md` | Minimum checks before returning each canonical output. |
| `output-contracts.md` | The sixteen canonical outputs and their required sections. |
| `offer-negotiation-preparation.md` | The canonical offer and compensation-negotiation preparation contract. |
| `state-management.md` | The Interview Journey State model and its context boundary. |

The full fifteen `frameworks/*.md` files are not duplicated here as flat Knowledge — their methodology is already adapted for progressive, in-conversation use inside the embedded Skill ZIP (`skill/interview-journey.skill.zip`). Uploading them again as raw Knowledge on top of the installed Skill would create redundant, potentially divergent copies of the same rules.
