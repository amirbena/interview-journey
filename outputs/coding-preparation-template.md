# Coding Preparation Template

Markdown presentation template for a Coding Preparation Session, built from a [Candidate Answer record](../schemas/candidate-answer.schema.md) (`answer_domain: Coding`) per [Framework 09 §21](../frameworks/09-coding-interview-decision-engine.md#21-required-outputs). All values below are synthetic.

## Disclaimer

> Hints escalate one level at a time; a full solution is shown only in Full Explanation mode or on explicit request.

## Guided Practice Output shape

- Current stage (per the [State Machine](../frameworks/09-coding-interview-decision-engine.md#6-standard-problem-solving-state-machine))
- Interviewer prompt
- Minimal hint when needed
- No hidden solution reveal

## Full Explanation Output shape

1. Problem Restatement 2. Constraints 3. Brute Force 4. Optimization Insight 5. Pattern 6. Algorithm 7. Code 8. Dry Run 9. Complexity 10. Common Mistakes.

## Review Output shape

1. Overall Assessment 2. Correctness 3. Reasoning 4. Complexity 5. Implementation 6. Edge Cases 7. Communication 8. Error Classification 9. Improved Direction 10. Interview Recommendation.

## Synthetic Example (Review Output)

**Problem:** Two Sum. **Pattern:** Hash Map. **Complexity:** O(n) time, O(n) space.
**Error Classification:** Boundary Error (off-by-one on the last index).
**Interview Recommendation:** Hire Signal — correct solution, minor boundary bug, clear communication.
