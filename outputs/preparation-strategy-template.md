# Preparation Strategy Template

Markdown presentation template for the Preparation Strategy output, built from a [Preparation Strategy record](../schemas/preparation-strategy.schema.md) per [Framework 06 Output](../frameworks/06-preparation-strategy-framework.md#output). All values below are synthetic.

## Disclaimer

> This plan targets only the topics that meaningfully increase the probability of passing the next interview — it is not a comprehensive syllabus.

## Required Sections

1. Objective
2. Priorities
3. Study Plan
4. Practice Tasks
5. Expected Outcomes

## Synthetic Example

### Objective
System Design preparation for the upcoming round at Northbridge Payments.

### Priorities
1. Idempotency and retries (Critical) 2. Cross-region consistency (High).

### Study Plan
- Review the outbox pattern.
- Review saga compensation flows.

### Practice Tasks
- Design a payment reconciliation system end to end.

### Expected Outcomes
Confidently justify consistency trade-offs under follow-up questioning.
