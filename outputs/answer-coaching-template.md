# Answer Coaching Template

Markdown presentation template for the Answer Coaching Review output, built from a [Candidate Answer record](../schemas/candidate-answer.schema.md) per [Framework 13 Output](../frameworks/13-answer-coaching-framework.md#output). All values below are synthetic.

## Disclaimer

> Coaching improves clarity and structure. It never invents experience the candidate did not have.

## Required Sections

1. Overall Assessment
2. Strengths
3. Weaknesses
4. Coaching Recommendations
5. Suggested Follow-up Questions
6. Improved Answer (optional)

## Synthetic Example

### Overall Assessment
Solid technical substance; missing a quantified result.

### Weaknesses
No measurable outcome stated for the caching redesign.

### Coaching Recommendations
Add the specific latency improvement figure (e.g., "reduced p99 latency by 40%") to make the impact concrete.
