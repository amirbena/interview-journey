# Mock Interview Scorecard Template

Markdown presentation template for the Mock Interview Scorecard output, built from a [Mock Interview Session record](../schemas/mock-interview-session.schema.md) per [Framework 12 Output](../frameworks/12-mock-interview-framework.md#output). All values below are synthetic.

## Disclaimer

> This scorecard reflects one simulated session. It estimates interview readiness — it is not a guarantee of the actual interview outcome.

## Required Sections

Interview Summary, Scorecard, Competency Breakdown, Technical Breakdown, Behavioral Breakdown, Key Risks, Preparation Plan.

## Synthetic Example

### Scorecard

| Area | Rating |
|---|---|
| Technical Knowledge | Strong |
| Architecture | Strong |
| Communication | Acceptable |
| Overall Recommendation | Strong |

### Key Risks
Underspecified failure handling for cross-region writes.

### Preparation Plan
Practice one more system design problem emphasizing failure handling and observability before the real interview.
